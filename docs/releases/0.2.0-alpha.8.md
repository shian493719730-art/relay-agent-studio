# Relay 0.2.0-alpha.8

新增「新手教程 → 从依赖到交付」，14步实际练习安装本地依赖、修改需求与源码、运行测试、操作真实页面、暂停、更改要求、新版验证、ZIP交付与本轮回滚。编号箭头指向实际控件与预览内按钮，保留现有布局、配色和按需浮层。

本课使用独立 Git/npm 工程，文件、进程、页面和 ZIP 都是真实结果；本地字段教学不进行 AI 理解，不调用收费模型，也不修改原项目或安装包。依赖来自随课文件，Git需本机安装，桌面自带 Node/npm。

课程可暂停、刷新和接续。暂停停止相关进程，保留源码、草稿和日志；继续课程不自动执行命令。源码按版本恢复，后续人工冲突不会被覆盖；日志与产物保留为历史副本。产物核对读取ZIP正文，保存成功以系统窗口结果为准。

201项离线测试，Mac/Linux安装包另核对实际本地依赖、测试、ZIP清单及环境恢复。支持macOS arm64与Linux x64；Windows不作为必需验收平台。收费模型端到端验收仍暂停。

正式项目开发仍支持用户允许的 Git/npm 脚本。课程不提供任意Shell、自动推送、部署或替换当前安装包；开发副本不是OS沙箱。AGPL-3.0-only及品牌规则继续适用。
