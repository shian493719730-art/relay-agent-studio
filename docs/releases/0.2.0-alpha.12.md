# Relay 0.2.0-alpha.12 · 面向教育场景的 Vibe Coder 体验优化

面向教育与初学创作场景优化核心使用流程，让交互反馈更即时、引导更直观、意图推敲更轻松：

- **常用创作意图灵感推荐（Starter Chips）**：
  - AI 操作助手面板空状态新增 4 组常用创作意图快捷气泡（策划与审查流水线、配置多模型团队、提取本地参考资料、诊断当前画板状态）；
  - 单击即可平滑填入需求输入框并聚焦，无需初学者手写复杂提示词，且绝不自动静默扣费或发起未确认的 API 请求。
- **项目属性面板实时就绪度引导（Readiness Guidance）**：
  - 在项目详情面板（`#pan`）实时评估项目创作要素（目标是否明确、是否只有单角色、是否缺少连线交付等）；
  - 智能显示通俗引导提示与一键就绪标志（`.pan-readiness`），引导学习者循序渐进完善项目规划。
- **一键目标推敲与回填（Goal Refinement）**：
  - 项目目标栏旁新增“✨ 推敲目标”快捷入口；
  - 深度联动提示词推敲工具（Prompt Refinement），推敲完成后可直接点击“设为项目目标”回填至项目描述，全流程支持画板撤销与重做。

维护平台为 Mac arm64、Linux x64；Windows 实验性。
