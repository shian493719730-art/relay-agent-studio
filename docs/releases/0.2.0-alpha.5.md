# 用自然语言开发 Relay

新手教程新增“用自然语言修改 Relay”：用户在内置助手输入需求，软件操作助手使用正式源码工具读取、修改、运行测试、查看差异、展示组件结果，并可回滚。保留既有布局、配色和沉浸式画板。

**本地课程不运行模型。** 它只提取本课引号中的助手开场文案，按明确的工具流程修改正式JSON源码的独立副本。文件、版本、测试退出码和组件预览均为实际结果，需求/测试文件只读，不用预设成功动画冒充验证。默认逐步执行，也可自动继续；支持暂停、刷新接续和按真实changeId回滚。

“准备真实AI开发（不执行）”提供仓库/权限/模型检查清单和自然语言草稿，复用同一组 dev.*。准备不启动推理；收费模型验收仍暂停。真实源码需要本机Git和项目环境，检查按用户账号执行，不是OS沙箱；源码预览不自动热替换安装包，不推送或部署。

发布验证包含186项离线测试，以及Mac/Linux实际安装包中的文案源码修改、内置Node测试、预览与回滚。Windows不作为必需验收条件；Mac社区包无Developer ID公证。源码及校验和随包提供，AGPL-3.0-only与品牌规则不变，旧MIT授权保留。
