# Relay 0.2.0-alpha.9 · 边做边学

Relay 继续保留可编辑画板、多模型团队和沉浸式工作方式，同时让初学者能理解每一步，而不是只照着点按钮。

- 核心能力课程拆成细微的实际操作，编号箭头只指可见控件。每课连接目的、操作、反馈、理解检查和迁移任务，支持上一课、暂停与继续。
- 悬停或键盘聚焦可读通俗解释，专业名称保留。源码、运行和自媒体课程补上目的及应看到的结果。
- 授权链路可以点击查看真实连接、已有范围、本人验证与断点接续。独立标明的三任务情境展示汇合、分流和单任务取消，不改变真实许可。
- 能力库默认使用自己配置的 API 给出最多十项排序推荐，其他候选与完整目录保持可见。自然语言目标不需要先猜英文工具名；失败会明确报告，不伪装为 AI 推荐。
- 宽窗口教学卡与助手分开放置，窄窗口紧凑显示；修复教程裁切、未保存目标丢失和课内 Prompt 结果在刷新后丢失的问题。历史进度、画板与草稿保留。

入口：新手教程 → 边用边学 · 核心能力。也可明确选择免费固定示范；API 实操会使用你自己的模型额度。官方、自有中转和本机兼容服务均可配置，中转模型名称由服务商声明。

本轮已在隔离环境完成八课本地教学实际操作，并真实调用 Claude 验证十项推荐及其他候选；不把本地情境称为真实登录或收费团队验收。Mac arm64 和 Linux x64 为维护平台；Windows 实验性，不作为本版本验收要求。安装说明见 [本地桌面部署](../DESKTOP.md)，教学方法与边界见 [学习指南](../LEARNING.md)。
