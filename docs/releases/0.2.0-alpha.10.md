# Relay 0.2.0-alpha.10 · 教学面板兼容修正

继续 Alpha9 的“边做边学”改造，并修正升级后恢复旧面板状态的两个问题：

- 教学面板之前已收拢时，保留可见的课程标题、展开和恢复默认大小按钮，避免空白栏。
- 切到其他画板时隐藏本课指引；回到课程画板再继续，不清空进度，也不自动重跑 API。

保留画板、草稿和课程记录。核心课程提供逐操作箭头、通俗解释、目的/预期结果、理解检查与迁移任务；授权可视化和最多十项 API 推荐继续保留。详见 [学习指南](../LEARNING.md)。

维护平台为 Mac arm64、Linux x64；Windows 实验性，不作为本版本验收要求。
