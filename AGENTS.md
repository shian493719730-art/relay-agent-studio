# Working on Relay

Read README.md, CONTRIBUTING.md and docs/ARCHITECTURE.md first. This is a local single-user Alpha. Use mocked providers in automated checks; real API spending needs an explicit task instruction. Never commit credentials, runtime data, browser profiles or personal evidence.

Preserve the editable immersive canvas, manual building, local drafts and user-chosen positions. New abilities need a manual entry, observable software action, real object IDs, a truthful result, and appropriate cancellation/undo. Local tutorial output and real provider execution must stay distinguishable.

Run npm run typecheck, npm test, npm run build and npm run check:public as appropriate. Check real UI behavior for UI changes. Do not claim cross-platform or provider compatibility from mocks alone.
