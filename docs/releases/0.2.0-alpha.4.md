# 人人都能自开发 · 源码新手课程

打开「新手教程 → 人人都能自开发」，跟随8步编号箭头，亲手读取实际源码、修改并保存、运行测试、查看差异、回滚，再运行测试确认恢复。源码面板也有课程入口，保留现有布局、配色和沉浸式画板。

- 独立的本地源码工程，正式文件桥实际落盘；桌面内置 Node 执行真实测试，不需要 Git/npm、API 密钥或依赖下载。
- 课程用一个刻意尚未满足的欢迎语需求：修改后测试通过，回滚后同一个断言再次失败；如实展示退出码，不把预设流程伪装成模型生成。
- 支持暂停、收拢、刷新后继续，保留草稿、日志和已完成操作；停止检查不算通过，恢复课程不自动重跑。
- 完成后连接自己的 Git 仓库，明确核对源码写入和检查脚本权限；人人拥有相同入口，不依赖维护者的路径或 API。自有仓库仍需 Git 与项目开发环境，AI 协作需自己的有效模型连接。

本地检查按用户账号执行，不是 OS 沙箱。课程不自动修改安装文件、不推送/部署，也不调用收费模型。AGPL-3.0-only 和品牌规则保留，旧 MIT 授权不撤回。

发布流程包含178项离线测试和实际安装包中的源码练习验证，维护范围仍为 macOS arm64、Linux x64；Windows不作为必需验收或发布条件。Mac 社区包没有 Developer ID 公证。
