# Relay 源码开发工作区

把真实源码连接到项目画板，供你和内置 Agent 一起开发，包括开发 Relay 自己。主布局、配色、网格和按需浮层保持原样。

## 新增能力

- 画板菜单、项目详情与项目聊天加入「源码开发」入口，可连接一个明确的 Git 仓库，创建统筹/实现/复核三角色开发项目。
- 实际读取 UTF-8 源码、分页浏览、手动编辑、精确替换、新建或删除文件。写入基于实际版本 hash，拒绝覆盖后来修改；手动草稿保留。
- 逐次差异、Git diff、回滚和重做。每次写入返回真实 changeId，不把画板撤销当作磁盘回滚。
- 运行已允许的 typecheck/test/build，显示实时日志和退出码，支持停止及保留结果。package.json 变化后重新核对检查权限。
- 内置助手可使用同一组 dev.* 软件动作，读取真实结果再继续；Playwright MCP 的浏览器可视操作保留。

普通桌面使用仍无需 Node 或 Codex；**源码开发检查另需本机 Git、Node/npm，Relay 构建还需 Python 3**。检查以你的账号权限执行仓库代码，不是操作系统沙箱。不会自动安装依赖、启动收费模型、Git 推送或部署。

## 平台与验证

当前维护与必需验收范围是 **macOS arm64、Linux x64**；Windows 不要求满足兼容、测试或发版条件，不默认出包。旧 Windows 附件仅作实验性参考。

发布流程需通过171项离线自动测试、构建和实际安装包检查。源码桥接验收使用隔离 Git 仓库和真实 npm 子进程，包括文件落盘、精确回滚、版本冲突、密钥/目录排除、草稿保护和停止进程组；操作规划使用测试夹具，不冒充收费模型验收。打包后另验证真实 PDF worker、本机服务隔离、离线对应源码，以及源码写入/恢复/实际检查命令。

Mac 社区构建仍无 Developer ID 公证；Linux 的全部发行版和完整实机界面尚未验收。收费模型端到端演练继续等待使用者的有效连接和额度，不在本轮自动执行。

## 下载与使用

下载适合平台的 DMG/ZIP 或 AppImage/tar.gz。升级只替换应用，独立用户目录保留；旧网页工作区不自动迁移。对应源码和 SHA256SUMS 同包发布。
