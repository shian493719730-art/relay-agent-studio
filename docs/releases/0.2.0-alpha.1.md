# Relay 本地桌面版

面向 vibe coder 的可视化办公软件：在原有沉浸式画板里组织不同模型、文件和项目，不必安装 Node、Python 或 Codex 即可打开桌面包。模型供应商、官方 API 或自选中转站由使用者配置，银子仅为可选推荐。

## 下载

- macOS Apple Silicon：arm64 的 DMG 或 ZIP。
- Windows：x64 的 setup.exe 安装包或 portable.exe。
- Linux：x64 的 AppImage 或 tar.gz。不同发行版的桌面依赖仍需按环境验证。
- source.zip 为本版本源码；SHA256SUMS.txt 用于核对下载文件。

这是早期测试版。社区构建没有 Apple Developer ID 公证或 Windows 商业签名证书；首次打开应在系统正常界面核对来源，项目不会关闭系统保护。当前未提供 macOS Intel 包。

## 本地部署与现有能力

- 桌面应用启动独立的本机服务，画板、草稿、文件正文和配置保存在自己的用户目录，升级替换应用时保留数据。
- 继续使用原布局、配色、网格和直接操控：手绘项目、独立模型绑定、统筹分工、成员执行、汇总、跨项目共享接续、暂停与更改要求，以及删除、撤销和恢复。
- Word、Excel、PDF 正文读取及关联阅读框；执行型内置助手与 Playwright MCP 可视操作入口。Playwright 仍需本机 Chrome，真实推理需要使用者自己的模型额度。
- 能力库提供开源资源目录、正文审阅和项目推荐；桌面版内置每7天的更新检查，可暂停、手动刷新和停止。只在应用运行时检查，错过后下次打开补检，不自动运行新资源中的代码。
- Prompt 优化与 Auth Relay 授权入口保留。Auth Relay 仍是可选的独立本机服务，本包未包含整个外部授权软件或新的授权；各能力的实际状态会显示在界面。
- 帮助菜单可查看完整许可，文件菜单可离线保存应用随附的对应源码。

桌面版与原网页工作区相互独立，本次不自动搬运或清空原网页数据，也没有一键完整迁移。安装、备份、升级和可选服务见 [桌面部署说明](https://github.com/shian493719730-art/relay-agent-studio/blob/v0.2.0-alpha.1/docs/DESKTOP.md)。

## 验证范围

发布流程须先通过 macOS、Windows、Linux 的162项自动测试、构建和每个系统打包后服务检查。打包检查使用真实 Electron/Node、独立临时目录、真实 PDF 解析进程，并验证未继承维护者 API 密钥、离线源码与服务隔离。

这些检查不等同于三个系统的完整人工界面验收。收费模型端到端复验按用户要求暂缓；此版本不宣称已重新跑过收费自媒体任务。主画板视觉沿用已认可版本。
