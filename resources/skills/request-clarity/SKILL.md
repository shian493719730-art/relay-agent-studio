# Clarify the request

An independently written Relay guide, distributed under the repository MIT license.

Read the original request before deciding on a structure. Identify its purpose, audience, supplied facts, and explicit limits. Preserve its language and tone. A short request can stay short.

Only add detail that makes the intended result easier to assess. Do not invent dates, permissions, budgets, sources, or success claims. Ask at most two questions if missing information materially changes the outcome. Explain which changes you made and why this request needs them.

This guide does not authorize execution, spending, account access, or publication.
