# Relay 可视执行时序修复

继承 Alpha 2 的完整源码开发工作区，修复实际无模型键鼠验收中发现的时序问题：更改要求尚未确认时，后续继续命令不能覆盖它；工作窗口按顺序完成命令后才确认回执。

保持现有布局、配色、网格和沉浸式体验。源码读写、测试/构建检查、差异回滚与重做可供内置软件操作助手调用，收费模型端到端验收仍等待使用者的额度。新增两项真实协议/前端调度回归用例，共173项离线测试。

支持范围仍为 macOS arm64、Linux x64；Windows 不要求满足兼容或发布条件。Mac 社区构建没有 Developer ID 公证。下载附件含对应源码和 SHA256SUMS；AGPL-3.0-only 与品牌规则保持。
