# Relay 0.2.0-alpha.13 · Vibe Coding 边学边教与沉浸式毛玻璃体验

本次更新深度整合 Claude Opus 5.5 教学设计规范，大幅强化面向初学者的“边学边教”辅助能力，并完成画板界面的质感精修：

- **改动点亮 + 一句话旁白（Change Highlight & Intent Callout）**：
  - AI 助手在画板落地项目、连线或文件时，对应阵地自动泛起微光光晕（`cl-node-illuminated`）；
  - 就近悬浮呈现通俗意图卡（明确“改了哪”、“为什么改”、“怎么验证”），并提供一键直达“查看源码 / 文件”的无缝检查通道。
- **断线诊断卡与熔断保护（Diagnostic Card & Circuit Breaker）**：
  - 遇到流程中断或连线异常时，提供「三层人话拆解」（发生了什么、在哪发生、真实底层报错代码）；
  - 提供零挫败互动排查测验，猜错温和解释原因不惩罚；
  - 内置连续 3 次尝试失败自动熔断机制，杜绝死循环烧 token，保护用户钱包。
- **亲手掌控旋钮（Hands-on Parameter Knobs）**：
  - 项目面板提供直观滑块，直接调节系统运行参数（如每页条数 `MAX_ITEMS`、刷新间隔 `REFRESH_SEC`）；
  - 数值改动实时映射到对应代码常量定义，初次滑动弹出温柔祝贺，打破新手修改代码的心理恐惧。
- **界面质感与视觉统一**：
  - 左右面板全面升级为克制透亮的苹果毛玻璃质感（`backdrop-filter: blur(20px)`），保留孟菲斯清爽办公配色与圆圈身份色；
  - 彻底去除跳动表情与廉价加载符号，操作反馈沉稳高效。
- **需求启发与 API 透明指引**：
  - 热门方向（GitHub Trending / Vibe Coding）与办公繁琐减负双 Tab 启发库；
  - 接入指引首推官方直连与免费额度，备选支持国内中转站，并醒目提示第三方中转稳定性与隐私风险。

维护平台：macOS arm64、Linux x64；Windows 实验性。
