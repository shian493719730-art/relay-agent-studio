# 路线图

这些是方向，不是发布时间承诺。欢迎先通过 Issue 对齐需求和验收方式。

## Alpha 已包含

- 可手动编辑的沉浸式画板、自由选区、项目组与共享连接。
- 成员独立模型连接、文件正文、统筹/成员/汇总/下游运行与暂停。
- 内置软件操作助手，Relay 同源 Playwright MCP 可视执行。
- 删除/撤销/恢复与近况、19 步无密钥教程、附加功能导览。
- Skill 目录、自有基础 Skill、Prompt 优化和可选本机授权适配器。

## 优先打磨

- 真实供应商的可复现兼容矩阵与额度/错误诊断；不保证中转上游身份。
- macOS / Linux 实机界面与浏览器会话验证，桌面签名公证和更完整的升级体验；Windows 不作为当前兼容、测试或发版要求，见[平台范围](PLATFORMS.md)。
- 无障碍、键盘与屏幕阅读器支持，窄窗口可用性。
- 更明确的撤销边界、持久恢复、导出/导入及完整文件备份。
- 接手/更改要求时的可观察一致性与更长工作流故障恢复。
- 英文 UI 与多语言文档。

## 后续探索

- Windows 的社区自愿适配；保留实验性配置与历史附件，不列为当前验收或排期承诺。

- 每周能力库调度的更多用户设置，以及来源许可、正文和运行结果追踪。
- 可安装插件的版本、权限和来源校验。
- 更丰富的文件处理与显式外部业务集成。
- 多人认证、远程部署与密钥加密方案；不能直接开放现有本地服务代替。

外部平台发布、任意桌面键鼠、任意 Shell、全量开源能力自动可用均不属于当前承诺。
