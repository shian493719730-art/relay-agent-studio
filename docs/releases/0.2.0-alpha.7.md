# Relay 0.2.0-alpha.7

正式开发支持连接自己的 Git/npm 工程，按具体需求安装依赖、改代码、运行脚本、预览应用和保存构建产物。沿用现有画板、配色和按需浮层。桌面版自带 Node/npm，Git 与 Relay 构建所需的 Python 由用户安装。

此版本修复真实桌面验收中发现的状态刷新问题：暂停步骤并等待进程退出后，运行、预览和打包按钮立即恢复；日志轮询仍保留预览 DOM 与手动输入。

继承 Alpha6 的独立开发副本、逐脚本许可、源码/锁文件版本冲突保护、本轮回滚点、进程组停止、实际 DOM/截图与带 SHA-256 的产物下载。恢复不会自动启动模型或命令。

196项离线测试；支持 macOS arm64 与 Linux x64，Windows 不作为必需验收平台。打包检查另使用实际依赖安装、HTTP 预览、Web ZIP 及源码/环境恢复。未调用收费模型，真实供应商自主开发端到端效果仍待充值后验收。

当前正式工具支持 Git/npm 项目，不提供无限制 Shell、自动 Git 推送、部署或替换当前安装包；独立开发副本不是操作系统沙箱，工程外和远端副作用无法一键恢复。AGPL-3.0-only 与品牌规则继续适用，旧发布不被覆盖。
