# 边做边学 Relay

Relay 同时是工作区和学习场所。目标是让使用者理解为什么这么做，能够观察和判断结果，最终把方法用到自己的工作里。

## 一课怎样进行

1. **理解目的**：先看这一步为什么必要，它在整个流程的哪个位置。
2. **亲手操作**：按编号箭头找到实际控件，点击、填写或选择。被遮挡的控件不会得到一个错误箭头。
3. **核对结果**：查看实际项目、方法正文、草稿、差异、进程或回执。说明文字本身不算完成证据。
4. **解释与判断**：用一道短问题检验概念，答案会解释原因。操作进度和理解检查分别记录。
5. **换个任务试用**：课程给出一个迁移任务，保留你手动搭建与修改的空间。

鼠标停在按钮、选项或输入框上，或用键盘聚焦，均可查看通俗解释。讲解不在悬停时调用模型。需要更深入的解释，可点“讲明白”；“让 AI 结合当前项目再讲一次”才会调用配置的模型。

## 入口与课程

点击“新手教程”，优先选择“边用边学 · 核心能力”。正常实操使用自己配置的 API，先搭工作区，再学习暂停接续、方法选择、Prompt 推敲、草稿和授权接力。缺少连接或额度时会明确提示。也可明确选择固定本地示范，标签会说明未调用模型。

另外保留自媒体协作、手动源码开发、自然语言开发和从依赖到交付课程。免费课程与真实 AI 实操有各自标签；本地预设结果不冒充模型推理。源码与运行课程使用真实工具回执，课程会说明修改、测试、预览和回滚的意义。

可以暂停课程、返回上一课、继续，也可收拢、拖动或调整面板大小。宽窗口中的助手和教学卡分开放置；窄窗口使用紧凑教练条和按需讲解。历史课程、原画板、已选方法与未发送草稿保留。恢复课程不自动恢复收费调用。

## 看懂项目工具库

| 名称 | 通俗理解 | 怎么判断有用 |
| --- | --- | --- |
| Skill | 教 AI 做事的小手册 | 阅读正文，判断方法是否适合本次目标 |
| 工作流 | 安排先后关系的接力路线 | 看清每一步输入、输出和何时交付 |
| 角色 | 团队的岗位说明 | 明确职责，另行绑定具体模型 |
| 工具或插件 | 真正读取文件或操作软件的能力 | 核对安装、服务连接、授权和实际运行结果 |

项目有已保存目标时，打开能力库会优先调用项目统筹或助手选用的 API。常用结果会在当前页面会话短时复用；修改目标或明确重新推荐才重新判断。前十项不足时如实少选，不虚构来源、不强行凑数。其他候选标明待进一步判断，完整目录仍可搜索和分页浏览。

推荐不代表安装；目录收录、正文读取、项目采用和运行验证是不同阶段。每周检查更新的是来源与目录，项目保留已采用的指南版本。应用须保持运行，目录不是实时全网扫描器。

## 看懂授权

授权图中的节点可以点击，分别解释提交请求、核对已有范围、本人验证和原断点接续，并显示本机实际状态。任务卡显示来源、状态和可用的原断点信息；只控制由本软件建立的任务。

独立标记的教学情境用三个任务展示汇合等待、一次本人验证、分流接续，以及只取消其中一个任务。它不创建真实账号授权，不证明真实登录，不改变许可。实际范围、有效期与开关由本人在 Auth Relay 原生面板确认。接力任务完成与业务成果是否正确仍要分别核对。

## 费用与模型

使用者可配置官方接口、自己的中转站或本机兼容服务，给不同成员绑定不同模型。API 实操、语义推荐、Prompt 优化和主动请 AI 讲解可能计费。没有 API 仍能使用画板和明确标记的本地课程。

中转线路的模型名称由服务商声明，不能凭名字确认与官方模型完全一致，质量与稳定性可能有差异。Relay 不绑定某个中转站。
