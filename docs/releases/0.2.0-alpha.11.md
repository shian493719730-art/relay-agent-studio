# Relay 0.2.0-alpha.11 · 高级开发者模式与操作助手工作流优化

面向 vibe coding 使用者优化核心工作流体验，降低界面认知负担，增强操作助手现场感知与非阻塞执行能力：

- **高级开发者模式**：默认隐藏源码操作区域，收纳为清晰可点击的模式切换入口；普通用户不被代码细节干扰，进入开发者模式后仍可完整使用 CAS 文件编辑、Git 差异对比、真实 npm 检查、运行时预览、检查点回滚与打包；切换模式不会丢失当前草稿与画布状态。
- **AI 助手非阻塞后台运行**：关闭助手面板仅隐藏浮层，后台 Agent 持续安全执行不被强行中止；顶部导航栏提供实时呼吸状态指示药丸，点击随时展开监控。
- **侧边自适应并排停靠**：在打开项目属性面板（`#pan`）时，助手面板（`#guide`）自动平滑停靠在左侧，实现双栏并排互不遮挡。
- **深度现场感知与反馈升级**：
  - 上下文自动识别当前画板、选中节点、单聊房间最新讨论与关联文件，明确代词消歧优先级规则，消除反问“你要操作哪个项目”的僵硬感；
  - 移除回复文字的 3 行强制截断，完整展示分析与执行计划；
  - 优化审批卡展示，明确调用模型名称、目标项目与安全边界。

维护平台为 Mac arm64、Linux x64；Windows 实验性。
