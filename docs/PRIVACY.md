# 数据与隐私

Relay 提供本地单用户桌面和源码部署，没有内置托管账号服务或产品分析埋点。

| 数据 | 默认位置 / 去向 |
| --- | --- |
| 画板、视口、草稿、编辑历史 | 当前来源的浏览器本地存储。不同浏览器/端口相互独立。 |
| 文件缓存 | 浏览器存储与本地文件服务；移除画板项目不等于擦除原文件。 |
| 执行记录、提取正文、成果 | 项目 `.data/`，或 `RELAY_DATA_DIR` 指定位置。 |
| API 密钥 | `.env.local` 或 `.data/model-connections.json` 等服务端本机配置；不应写入客户端资源。 |
| 实际模型请求 | 你选择的供应商/中转端点；包含任务和该执行选择的材料/共享内容。 |
| Skill / Workflow 正文与刷新 | 所选公开来源的网络请求；不是无网络离线功能。 |
| 可视浏览器 | 本机专用 Chrome 会话与 Relay 同源状态桥；不是用户全部浏览器历史访问器。 |
| Auth Relay | 若安装并启用，连接本机外部应用；范围由已有授权决定。 |

密钥是本地文件存储，**没有实现加密保险箱**。文件权限与同源检查降低意外暴露，不替代设备安全。不要共享完整运行目录，不要把服务暴露到公网；本版本没有远程身份认证和多人租户隔离。

本地教程使用虚构材料，不调用模型、不登录社交平台、不真实发布。实际任务和连接检查可能产生费用；收费操作应由用户明确开始。停止会终止后续调度并尝试取消当前请求，但无法撤销供应商已经完成的计算或计费。

备份需同时考虑服务端数据、浏览器工作区和文件原件。通过界面移除对象属于工作区编辑，并非隐私擦除。想清理本机数据时先停服务并确认备份，再使用操作系统/浏览器的正常数据管理功能。

本公开仓库只含项目源码、公开来源元数据、文档和虚构演示，不包含开发者的 API 密钥、个人任务、浏览器配置或真实业务文件。

桌面版在 Electron 的 appData 目录下使用独立的 Relay Agent Studio 文件夹，窗口存储来源固定为 relay://workspace，服务端只监听随机回环端口并要求进程会话凭据。应用不继承开发工作区的模型密钥或数据目录；每周资源检查仅在应用运行时发起公开来源请求，能够暂停，不调用模型。升级不清空该数据目录。完整位置与备份范围见 [桌面部署](DESKTOP.md)。
