# 快速开始 / Quick start

## 环境

- Node.js 24 或更高版本，npm；Python 3，并确认 `python3 --version` 可执行。
- 普通画板使用现代桌面浏览器。Playwright 可视模式还需本机 Google Chrome；安装依赖并不自动安装 Chrome。
- 当前实际验证平台为 macOS。仓库 CI 覆盖计划包含 Linux、macOS、Windows；桌面应用适配器 Auth Relay / Snapper 只面向 macOS。

```bash
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4317/design-v2/ 。用底部/右下「新手教程」开始无密钥演练；点击左上画板名创建自己的空画板。教程是独立练习空间，退出保留原画板与草稿。

## 配置模型

1. 打开顶部「连接」，添加一个连接，选择协议并填写 API Base URL、准确模型 ID 和密钥。
2. 官方服务和兼容中转均可配置。不知道模型 ID 时查该供应商文档，不能仅凭头像推断。
3. 检查连接会发出实际请求，可能收费。不要在额度用完时反复点击。
4. 在项目中增减成员，指定职责和各自的连接。两个相同品牌成员也能绑定不同模型。
5. 拖入需求文件、检查正文，确认后明确开始任务。连接成功不代表已经运行团队。

`.env.local` 是可选的官方密钥方式，复制 `.env.example` 后填入；优先使用界面连接管理以独立绑定模型。不要把密钥写进前端、截图或 GitHub Issue。模型的存在、额度与输出质量取决于实际端点，不保证“所有模型”均可用。

## 文件与连接

文件可拖到画板、项目或聊天输入区，也可点文件/附件。支持 DOCX、XLSX、文本型 PDF、常见文本；扫描件需要预先 OCR。上传后可查看提取状态，失败有明确反馈。阅读框可以移动和缩放并连回项目。

用「连线」连接两个或更多项目；点连线设置共享内容和触发条件。下游只读取明确共享的上下文，不把其他无关项目材料一起发给模型。暂停连接保留关系；恢复不会默默补发所有历史事件。

## 控制执行

运行时可暂停、停止、修改要求。删除/撤销结构编辑会停止受影响对象，已有记录保留；恢复对象后需主动继续。移动、缩放不停止其他项目。打开「近况」查看画板回报，项目和项目组也有自己的范围。

教程 19 步覆盖删除、撤销、重做、恢复和项目组；亮点导览介绍助手、能力库、Prompt 和授权。样例发布不会发送到真实社交平台。

## 数据与更新

- 服务数据默认在 `.data/`，可通过 `RELAY_DATA_DIR` 指定目录。
- 画板、草稿、编辑历史和文件缓存也保存在浏览器本地存储中；更换端口/浏览器会成为不同工作区。
- 密钥配置位于本地服务端文件，保护好 `.env.local`、`.data/` 和设备账号。
- 更新前停止服务，备份服务数据及通过界面导出的画板（导出不等于包含全部文件原件）。不要清理浏览器数据，除非已确认备份可恢复。
- 然后 `git pull --ff-only`、`npm ci`、`npm run build`、`npm start`。

自定义端口：在 `.env.local` 设置 `PORT=4318`，重启后打开相应 URL。服务只监听回环地址；当前没有远程多人部署的登录系统。

## 本地开发

`npm run dev` 启动开发服务；修改 `src/prototype` 后运行 `npm run build` 重新组装主画板。生产入口为 `/design-v2/`；根路径的 React 工作台是早期入口，不等同于新画板。`npm test` 使用模拟供应商，不要求实际 API 密钥。
